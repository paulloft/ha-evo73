# История изменений

## 1.3.1

- После успешного открытия двери из веб-интерфейса, Home Assistant, REST API или режима «Жду курьера» сбрасывается текущий входящий SIP-звонок этого домофона.
- При ошибке открытия звонок продолжается. Звонки других домофонов не сбрасываются.
- Повторные SIP-пакеты завершённого звонка не возобновляют вызов и не создают повторных уведомлений, в том числе после переподключения TCP.

## 1.3.0

- Добавлен режим «Жду курьера»: первый входящий звонок открывает первую дверь и автоматически выключает режим.
- Переключатель доступен в веб-интерфейсе и интеграции Home Assistant отдельно для каждого домофона.
- Режим выключается перед попыткой открытия, в том числе при ошибке команды. После перезапуска дополнения режим выключен.
- Имитация звонка не открывает дверь и не выключает режим.

## 1.2.1

- Добавлена локальная иконка интеграции Home Assistant в `custom_components/evo_doorphone/brand/icon.png`.
- В HACS 2.0.5 иконка может не отображаться из-за ошибки загрузки локальных иконок в самом HACS.

## 1.2.0

- Добавлена интеграция EVO Doorphone с настройкой через интерфейс Home Assistant и установкой через HACS.
- Для каждого домофона автоматически создаются устройство, кнопка открытия двери, камера и сущность события входящего звонка.
- Добавлен локальный API дополнения для интеграции: список домофонов, открытие двери, снимки, видеопоток и события звонков.
- Авторизация и токены EVO остаются в дополнении. Для работы интеграции не требуется настройка YAML или HTTP-вебхука.
