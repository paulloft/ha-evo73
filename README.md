# Интеграция домофона EVO73 в Home Assistant
Работа дополнения возможна только с домофонами компании [EVO](https://www.evo73.ru/)

## Возможности интеграции
- Открытие двери
- Отправка вебхука при звонке в домофон с нагрузочными данными
- Получение ссылки на стрим с камеры
- Получение изображения с камеры
- Режим "Жду курьера". Открывает дверь при звонке и выключается

## Чек-лист для правильной работы интеграции
- Домофон с камерой от компании EVO
- Наличие зарегистрированного аккаунта с возможностью входа в мобильное приложение
- Оплаченный тариф

## Установка дополнения
Добавьте репозиторий дополнения в ваш Home Assistant

[![Open your Home Assistant instance and show the add add-on repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fpaulloft%2Fha-addons-repo)

Сверху справа нажмите три точки и выберите пункт «Проверить наличие обновлений» и перезагрузите страницу. После этого в списке появится репозиторий с дополнением.

## Первичная авторизация
Для создания токенов доступа откройте Web-интерфейс дополнения и нажмите «Запросить звонок». Введите последние 4 цифры входящего номера и нажмите «Авторизоваться».

Можно выбрать «Запросить СМС» и ввести код из сообщения. Используйте код от последнего запроса: способ подтверждения должен совпадать со способом получения кода.

На указанный в настройках номер телефона должно прийти СМС с кодом, который необходимо ввести в соответсвующее поле и нажать кнопку «Авторизоваться»

## Автоматическое создание сущностей

[![Добавить репозиторий EVO Doorphone в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=paulloft&repository=ha-evo73&category=integration)

Начиная с EVO 1.2.0 доступна отдельная интеграция **EVO Doorphone** для Home Assistant 2026.10+. Установите её через HACS как пользовательский репозиторий `https://github.com/paulloft/ha-evo73` с типом «Интеграция», перезапустите HA и добавьте EVO Doorphone через «Настройки → Устройства и службы».

После подключения к внутреннему адресу дополнения (обычно `http://961868a2-doorphone`) для каждого домофона автоматически создаются устройство, кнопка открытия двери, камера с живым видео, сущность события звонка и переключатель «Жду курьера». YAML и HTTP-вебхук для этого не нужны. Авторизация EVO остаётся в веб-интерфейсе дополнения.

[Установка, переход с Python-форка и использование сущностей](custom_components/evo_doorphone/README.md).

## Жду курьера

Включите переключатель «Жду курьера» в карточке нужного домофона или на его устройстве в Home Assistant. Первый входящий SIP-звонок выключит режим и отправит одну команду открытия первой двери этого домофона. Другие домофоны имеют независимые переключатели. Звонок по-прежнему создаёт событие HA и отправляет вебхук, если он настроен.

Режим выключается перед отправкой команды: при ошибке открытия повторных попыток не будет. Чтобы разрешить следующую попытку, включите режим заново. Повторные пакеты уже обработанного звонка не расходуют повторное включение. После перезапуска дополнения все переключатели выключены. Кнопка «Имитировать звонок» дверь не открывает и режим не выключает.

Открытие выполняет само дополнение, даже если Home Assistant недоступен. Веб-интерфейс обновляет состояние раз в 15 секунд, интеграция — после события звонка и при опросе устройств раз в минуту. Для новой сущности обновите и дополнение, и интеграцию через HACS, затем перезапустите HA.

## Ручная настройка через REST и вебхуки

При использовании EVO Doorphone настройки из этого раздела необязательны.

### Служба для открытия двери
Для создания службы необходимо в `configuration.yaml` добавить строки

```yaml
rest_command:
  doorphone_open:
    url: 'http://961868a2-doorphone/open'
    method: GET
```

### Создание автоматизации с отправкой уведомления
Создайте новую автоматизацию

[![Open your Home Assistant instance and show your automations.](https://my.home-assistant.io/badges/automations.svg)](https://my.home-assistant.io/redirect/automations/)

В качестве тригера использовать получение полезных данных Webhook

В качестве действия использовать отправку уведомления

Пример отправки уведомления в текстовом формате

```yaml
action: notify.notify
metadata: {}
data:
  title: Кто-то звонит в домофон
  message: 🏠 {{ trigger.json.address }}
  data:
    image: "{{ trigger.json.snapshot }}"
    actions:
      - action: rest_command.doorphone_open
        title: Открыть дверь
```

Полезная нагрузка данных в webhook:
- address: Адрес звонящего домофона
- apartment: Квартира звонящего домофона
- entrance: Номер входа, откуда происходит звонок
- openDoorUrl: Ссылка на открытие двери (Должна быть открыта методом POST)
- snapshot: Ссылка на снапшот с камеры
